# API Reference

Doxygen extracts declarations and contracts directly from include/ and combines
them with docs/ Markdown pages. Build from the repository root with
`doxygen docs/Doxyfile`; HTML appears in docs/output/html.

The @ref dev_index "developer index" explains invariants and implementation
boundaries; the @ref python_api "Python reference" describes bindings.
Edit these sources instead of generated HTML.
